# Founder Workflow for ChatGPT 日本語版

**非公式・会話用アレンジ / v0.1.0 / 2026-10-25**

事業アイデアを、競合・顧客の反論・価格・採算・実地検証の順に整理する日本語プロンプトです。原作 [Founder Skill](https://github.com/Jakeschincariol/founder-skill) の 11 分野を、通常の ChatGPT の会話で扱いやすく再構成しました。

## 10 秒で試す

[日本語プロンプトを開く](./Founder_ChatGPT_日本語プロンプト.txt) → 全文をコピー → 新しい ChatGPT の会話へ貼り付けて「開始。事業案は○○です」と送ってください。ファイル画面の **Raw** から本文だけを表示できます。

ゲームなら、本体の後に [ゲーム向け追加プロンプト](./GAME_ADDON.txt) を貼るだけ。最初の相談には [入力テンプレート](./INPUT_TEMPLATE.txt) も使えます。

## 3 ステップで使う

1. `Founder_ChatGPT_日本語プロンプト.txt` の全文を、新しい ChatGPT の会話に貼り付ける。
2. 「開始。事業案は〇〇です」と送る。詳しく入力したければ `INPUT_TEMPLATE.txt` を使う。空欄は不明でよい。
3. 質問に答え、「次へ」「価格だけ」「仮想顧客を 5 視点で」のように進める。

添付できる環境なら TXT を添付し、「このファイルを会話用の指示として使い、開始して」と伝えても構いません。本文を読み込めない場合はコピーして貼り付けてください。ZIP は配布用です。ChatGPT には中の TXT を使います。

### 最短の入力例

> 開始。個人事業主向けに、予約確認の作業を減らすサービスを考えています。月額価格は未定。まずアイデアの弱点と、実際の人に何を聞くべきか教えてください。仮想顧客は 5 視点まで。

これは例文であり、実在の事業や顧客についての情報ではありません。

## できること

1. アイデアを 3 つの観点で検討
2. 出典つきの競合調査、または未調査リスト
3. 5〜10 視点からの架空の反応。必要なときだけ 20 視点へ拡張
4. 価格のテスト候補
5. 提供内容・保証・購入障壁の見直し
6. 原価・貢献利益・損益分岐・感度分析
7. 集客と計測の計画
8. 名前・ブランドの制作ブリーフ
9. 運営手順と原価・能力の確認
10. 実際の人で確かめる小さなテスト
11. 根拠と未確認事項を分けた事業計画

英語名との対応と変更点は `ATTRIBUTION.md` にあります。

## できないこと・注意点

- インストール型の ChatGPT スキルではありません。合図の名前はこの会話内だけのものです。
- 100 人の独立エージェントを実行しません。同じ AI による複数観点の整理です。
- 架空の反応は顧客調査、需要予測、口コミ、売上予測ではありません。人数を増やしても現実の証拠にはなりません。
- 検索・計算・ファイル機能の有無は利用環境によります。使えない機能は実行済みとせず、資料提供や手計算に切り替えます。
- 原作の 4 本の Python ツールは移植・同梱していません。Van Westendorp の価格曲線や自動判定を再現したものではありません。
- 貼り付けて使う方式自体に API キーは不要です。ChatGPT の利用条件・利用上限は利用者の環境に従います。この配布物は ChatGPT の利用権を付与しません。
- 出力は毎回同じとは限りません。計算と引用を確認してください。会話をまたぐ引き継ぎには「保存用まとめ」をコピーします。
- 外部送信・広告・購入・公開は実行しません。法務・税務・許認可・商標は公式情報と専門家で確認してください。
- 顧客情報や社外秘資料を入れる場合は、共有権限を確認して匿名化してください。パスワードや秘密鍵は入れないでください。

## ファイル

- `Founder_ChatGPT_日本語プロンプト.txt`：この 1 ファイルだけでも利用できる本体。ライセンス通知を内蔵。
- `INPUT_TEMPLATE.txt`：入力用紙。
- `GAME_ADDON.txt`：ゲーム向けの任意の追加指示。初見の遊び・再プレイ・実プレイ観測を整理。
- `EXAMPLE_FICTIONAL.txt`：全データが架空の、計算と判断の見本。市場調査結果ではない。
- `TEST_CHECKLIST.md`：確認済み項目と、利用時に確認する挙動。
- `ATTRIBUTION.md`：原作・参照コミット・11 分野の対応・変更点。
